# 🛍️ Online Shopping System (C++)

Welcome to the **Online Shopping System** repository! This project is a console-based application written in C++ designed to simulate a real-world e-commerce platform. It manages core shopping operations such as product catalog browsing, cart management, user authentication, and order checkout.

🌐 **Repository Link:** [https://github.com/FariaSajid/Online-Shopping-system](https://github.com/FariaSajid/Online-Shopping-system)

---

## ✨ Features

- **User Authentication:** Secure registration and login system for customers and administrators.
- **Product Catalog:** Browse through various product categories, view item details, prices, and stock availability.
- **Shopping Cart Management:** Add items to the cart, update quantities, remove products, and calculate the total bill.
- **Order Checkout & Billing:** Seamless checkout process generating an itemized receipt/invoice.
- **Admin Controls (Optional/Extensible):** Manage inventory, add new products, and track user orders.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C++
- **Key Concepts:** 
  - Object-Oriented Programming (OOP) principles (Classes, Encapsulation, Inheritance)
  - Data structures (Vectors, Arrays, Structs)
  - File handling (for saving user data and product inventories)
  - Console-based user interface (CLI) and input validation
